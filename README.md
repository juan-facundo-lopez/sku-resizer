SKU-Resizer
Automation for E-commerce Workflows

Stop wasting time on manual image formatting. SKU-Resizer is a streamlined tool designed to bridge the gap between Design and E-commerce teams by automating image adaptation for product listings.

💡 The Problem vs. The Solution
The Pain Point: The E-commerce team frequently required manual image resizing for different SKUs, creating a bottleneck for the design department and slowing down product launches.
The Fix: A self-service Streamlit web app that allows non-technical users to upload raw assets and receive perfectly formatted images in seconds.

✨ Key Features
Batch Processing: Upload multiple images and process them at once.
E-commerce Optimized: Tailored aspect ratios and padding for major marketplaces.
Zero-Friction UI: Built for speed—no design software knowledge required.
Instant Download: Automated ZIP generation for seamless workflow integration.

🛠️ Tech Stack
Frontend/Backend: Streamlit
Image Processing: Pillow (PIL)
Language: Python

📈 Why this matters
By implementing this tool, we reduced the image preparation turnaround time by 80% and eliminated repetitive manual tasks for the design team, allowing us to focus on high-value creative work.
